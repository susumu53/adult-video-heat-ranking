# 6サイト横断 動画過熱感（急度）ランキングシステム 設計書

**作成日**: 2026-07-24  
**ステータス**: 承認済み設計  
**インフラ構想**: GitHub Actions + GitHub Pages（完全無料・全自動運用）

---

## 1. システム概要と目的

Pornhub, XVideos, SpankBang（世界トレンド）および TokyoMotion, FC2動画, MissAV（日本固有・素人・JAVトレンド）の計6サイトを横断し、単なる累計再生数ではなく**「直近で急速に再生数が伸びている過熱感の高い動画」**を日別・週別・月別・年別ランキングで視覚化・紹介するWebアグリゲーター。

## 3. インフラ・自動化設計 (GitHub Stack)

- **データ収集バッチ (GitHub Actions)**:
  - 1日4回（6時間間隔）`cron: '0 */6 * * *'` でPython/Node.jsクローラーを自働起動。
  - 各サイトから上位500件のメタデータを取得し、過去データとの時系列差分を計算。
  - 結果を `data/rankings.json` および `data/history/` に保存し、自動 `git commit & push`。
- **Webフロントエンド (GitHub Pages)**:
  - Vite + React + Vanilla CSS (または HTML/JS) によるモダンな超高速レスポンシブWeb UI。
  - `data/rankings.json` を非同期読み込みし、爆速で表示。

## 4. 過熱感（急増度）アルゴリズム

単なる累計再生数ではなく、以下の式で「今バズっている度合い」をスコア化。

$$\Delta V_{24h} = V_{\text{現在}} - V_{24\text{時間前}}$$

$$\text{Heat Score} = \frac{\Delta V}{\log_{10}(V_{\text{初回計測}} + 1000)} \times \text{Freshness Factor}$$

- **フィルター区分**:
  - **期間**: 【日別 (24h)】 【週別 (7d)】 【月別 (30d)】 【年別 (365d)】
  - **サイト**: 【全サイト】 / 6サイト個別に絞り込み
  - **地域/ジャンル**: 【総合】 【日本(UGC/素人)】 【海外トレンド】 【JAV作品】

## 5. UI/UX デザイン設計

- **カラーパレット**: ダークネイビー背景 (`#0B0F19`) + ネオンピンク/アクアアクセント (`#FF2A6D`, `#00F5FF`)。
- **ヒーローエリア**: 本日一番バズっている「🔥 本日の超急上昇No.1動画」のフィーチャーカード。
- **カードレイアウト**: ホバー時のプレビュー＆拡大、過熱度メーター（`🔥 Heat 98/100`）、24h増加数デジ表示（`+54.2k views`）。
